# Chart1 改进图说明

> **原图来源**：<https://observablehq.com/@d3/chord-diagram>

## 一、原图存在的问题

### 1. 颜色可区分性差

原图使用 `d3.schemeCategory10`，当类别数量较多时颜色重复或相近，难以分辨，且对色盲用户极不友好。

**原图（正常视觉）**

![原图 - 正常视觉](C:/Users/a2545/Desktop/original_chord.jpg)

**红绿色盲视角下的原图**

![原图 - 红绿色盲模拟](C:/Users/a2545/Desktop/original_chord_deuteranopia.jpg)

**色盲视角下原图丢失了什么**：

- **LG 的品红 / 粉色** → 变为灰褐色,与 **HTC 的灰色** 几乎无法区分,两个相邻弧段的品牌塌陷在一起。
- **Huawei 的亮绿** → 变为芥末黄;**Sony 的深绿** → 变为卡其 / 暗黄褐,与周围灰色弧段在色相上趋同,只能靠明度勉强区分。

### 2. 扩展性差

当数据规模非常大时,原图可视化交互非常弱,仅显示不直观的数据框,且众多线条聚在一起时混乱难以阅读。

### 3. 缺乏方向性表达

原图同一品牌使用单一颜色,分不清是品牌流出还是流入,长时间观看会引发视觉疲劳。

### 4. 信息粒度不足

当想具体了解某个品牌时,原图信息粗略,需要逐个查找,难以得到直观有用的信息。

### 5. 忠实用户视觉混乱

忠实用户占很大一部分群体且不与其他品牌交互,原图却将其放在内圈,导致:

- 内圈拥挤、混乱;
- 忠实用户视觉上往中心凹陷,与品牌间切换流混在一起;
- 容易让人误以为这条粗弦也是切换。

### 6. 流失用户轨迹不清晰

之前切换走的用户,看不到这部分在图上对应哪里。视觉上只有流入本品牌的内弦,流出的信息只是一个数字。

## 二、改进策略

### 1. 色盲友好配色

替换为色盲友好配色,使用 `d3.schemeTableau10`(色盲安全),7 个品牌色对比度更友好。

![色盲友好配色效果](C:/Users/a2545/AppData/Roaming/Typora/typora-user-images/image-20260520225447934.png)

### 2. 强化可视化交互

新增**悬停弹出效应**——当悬停品牌弧或某个品牌时,会淡化非相关品牌、强化目标品牌,颜色加深,更清晰地看出品牌之间的关系。

![悬停交互效果](C:/Users/a2545/AppData/Roaming/Typora/typora-user-images/image-20260520225526099.png)

### 3. 线性渐变增强方向性

对每个品牌增加渐变填充,使用**线性渐变**表达方向性,让用户一眼看出从哪个品牌切换到了哪个品牌,补强了原版缺失的方向编码。

### 4. 品牌详情页功能

新增**点击品牌进入详情页**功能:

- 点击品牌,整个 SVG 替换为该品牌的详情视图;
- 点击详情页顶部的品牌名可返回 chord 视图;
- 用户可对某个具体品牌了解到更详细的数据,以及该品牌与其他品牌的具体关联;
- 悬浮品牌上方时,数据详情卡片变得更加具体,新增**总人数、忠诚用户、从他牌切换而来用户、流走用户**等指标,并配有不同颜色高亮,更加直观具体。

![品牌详情页效果](C:/Users/a2545/AppData/Roaming/Typora/typora-user-images/image-20260520225555446.png)

### 5. 忠实用户外圈凸起

忠实用户从内圈自环改为**外圈凸起**:

- 没换品牌的人 → 往外凸起;
- 换了品牌的人 → 内部连线;
- 两类数据用方向相反的视觉编码分离,不再有冗余的自环占据视觉空间。

### 6. 流失用户可视化

改进"流出去的用户"在图上的可视表达:在他牌弧的对应内弦段上覆盖一块**本品牌色 + 深色描边**的弧段,用来描述"原本品牌流走到他牌的人",宽度精确等于 i → j 的人数。
