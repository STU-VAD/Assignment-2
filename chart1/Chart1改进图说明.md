# Chart1改进图说明

原图选自：https://observablehq.com/@d3/chord-diagram

## 原图存在的问题

1. **颜色可区分性差**：原图使用 `d3.schemeCategory10`，当数量多时颜色重复或相近导致难以分辨，对色盲不友好。

2. **扩展性差**：当数据规模非常大时，由于原图可视化交互非常差，仅仅显示不直观数据框，且当众多线条聚在一起，导致混乱难以阅读。

3. **缺乏方向性表达**：原图同一品牌使用单一颜色，分不清是品牌流出还是流入，长看会引发视觉疲劳。

4. **信息粒度不足**：当想具体了解某个品牌时，原图信息粗略，得逐个查找，难以得到直观有用的信息。

5. **忠实用户视觉混乱**：忠实用户占很大一部分群体且不与其他品牌交互，原图还放在内圈，导致内圈拥挤、混乱，忠实用户视觉上往中心凹陷，与品牌间切换流混在一起，容易让人误以为这条粗弦也是切换。

6. **流失用户轨迹不清晰**：之前切换走的用户，看不到这部分在图上对应哪里，视觉上只有流入本品牌的内弦，流出的信息只是个数字。

## 改进策略

1. **色盲友好配色**：替换了色盲友好配色，使用 `d3.schemeTableau10`（色盲安全），7个品牌色对比度更友好。

2. **强化可视化交互**：悬停弹出效应——当悬停品牌弧或某个品牌时，会淡化非相关品牌，强化目标品牌，颜色加深，更好的看出品牌之间的关系。

3. **线性渐变增强方向性**：对每个品牌增加了渐变填充，使用线性渐变，更好的表达方向性，让用户一眼看出从哪个品牌切换到了哪个品牌，补强了原版缺失的方向编码。

4. **品牌详情页功能**：新增点击品牌进入详情页功能——点击品牌，整个SVG替换为该品牌的详情视图；点击详情页顶部的品牌名返回chord视图。使用户对某个具体的品牌可以了解到更详细的数据，每个品牌与其他品牌的具体关联。悬浮品牌上方时数据详情卡片变的更加具体，新增总人数，忠诚用户，从他牌切换而来用户，流走用户等，并配有不同颜色高亮，更加直观具体。

5. **忠实用户外圈凸起**：忠实用户从内圈自环改为外圈凸起：没换品牌的人 → 往外凸起，换了品牌的人 → 内部连线，两类数据用方向相反的视觉编码分离，不再有冗余的自环占据视觉空间。
   
6. **流失用户可视化**：改进"流出去的用户"在图上的可视表达，在他牌弧的对应内弦段上覆盖一块本品牌色+深色描边的弧段，用来描述"原本品牌流走到他牌的人"，宽度精确等于 i→j 的人数。
